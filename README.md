# 🚀 CBBlogs — Personal Blogging Platform with CMS

> ✍️ Write freely. ⚙️ Manage effortlessly. 👥 Engage your audience.

CBBlogs is a **personal blogging platform powered by Flask**, designed for a single admin to publish content while allowing users to **interact, follow, and explore posts seamlessly**.

It combines a **lightweight CMS** with **user engagement features** like favorites, comments, and search — making it more than just a static blog.

## ✨ Core Concept

- 🧑‍💻 **Admin-controlled content** (no public posting)
- ⚙️ Built-in **CMS for dynamic blog management**
- 👥 Users can **interact, save, and stay updated**

---

## 🔥 Features

### ⚙️ Admin CMS
- Create posts dynamically from dashboard  
- Edit and delete posts  
- Full control over published content  

### 📝 Blogging System
- Dynamic post rendering  
- Markdown support for rich formatting  
- Clean and structured UI  

### 👤 User System
- User signup & login  
- Subscribe to stay updated with new posts  

### 💬 Engagement Features
- Comment on blog posts  
- Like posts  
- Interactive reading experience  

### ⭐ Favorites System
- Save posts to favorites  
- Quickly access saved content later  

### 🔍 Search Functionality
- Search posts easily  
- Fast content discovery
